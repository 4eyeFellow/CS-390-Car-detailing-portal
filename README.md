**Current Practice**

The current scheduling system for Evansville Mobile Car Detailing is through phone calls, texts, messages via social media (facebook and instagram), and word of mouth. The owner has to keep up with messages in multiple places communicate back and forth with each client to collect all the needed contact information, vehicle info, desired services location and time. This information is manually collected and used to calculate how long the job should take, which depends on both the services selected and how long the commute is. The appointment is manually put on a Google Calendar.

**Problem**

 Evansville Mobile Car Detailing is a new business, with a rapidly growing clientele. As the number of clients increases keeping track of these various, scattered forms of communication is becoming increasingly difficult and time consuming. Scheduling requires more than just finding an open time. It must account for different detailing levels and add-ons, and, since the business is mobile, the location of each client and travel time between appointments also needs to be considered. Managing all of this manually takes time away from actual jobs and creates more opportunities for scheduling mistakes.
